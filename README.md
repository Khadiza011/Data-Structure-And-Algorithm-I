# Data Structures and Algorithms - I (DSA-I)

Welcome to my **Data Structures and Algorithms - I (DSA-I)** repository!

This repository contains my C++ implementations, laboratory exercises, and practice problems for the DSA-I course. The goal is to understand fundamental data structures and algorithms through simple, well-organized, and beginner-friendly code.

All programs are developed using **C++** and can be compiled and executed using the **Code::Blocks IDE**.

## Topics Covered

- Searching
- Sorting
- Linked List
- Stack
- Queue
- Upper Bound & Lower Bound
- Binary Search Tree (BST)
- Heap & Priority Queue
- Topological Sort
- Tower of Hanoi
  
## Language and Development Environment

- **Programming Language:** C++
- **IDE:** Code::Blocks
- **Compiler:** GNU GCC / MinGW
- **Standard:** C++11 or later

## How to Run the Programs

Follow these steps to run a program using Code::Blocks:

1. Install and open Code::Blocks with a working C++ compiler.
2. Create a new **Console Application** or open an existing C++ project.
3. Select C++ as the programming language.
4. Add or open the required `.cpp` source file.
5. Click **Build and Run** or press `F9`.
6. View the program output in the console window.

### Compile Using GCC

If GCC is available in your terminal, you can also compile a program with:

```bash
g++ -std=c++11 LinearSearch.cpp -o LinearSearch
```

Run the generated executable:

**Windows**
```bash
LinearSearch.exe
```

**Linux / macOS**
```bash
./LinearSearch
```

Replace `LinearSearch.cpp` with the filename of the program you want to compile.

## Learning Approach

Each program is intended to be easy to read and understand.

Whenever appropriate, implementations include:

- Clear comments explaining important steps.
- Meaningful function and variable names.
- Sample inputs and outputs.
- Simple logic suitable for beginners.
- Separate source files for individual topics.
- Time and space complexity explanations.

The focus is on understanding the logic behind each algorithm rather than memorizing code.
